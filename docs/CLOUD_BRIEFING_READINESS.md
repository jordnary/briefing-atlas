## 1. 已确认的运行方案

采用 **GitHub Actions + OpenAI 官方 Responses API + 独立公开静态仓库的 GitHub Pages**。用户已在本轮明确选择 OpenAI 官方 API。内容继续以 `content/briefings/YYYY/MM/YYYY-MM-DD.md` 为唯一正式稿；现有 Sites 作为过渡预览。

```mermaid

    A[私有源码仓库] --> B[Actions 采集和生成]
    B --> C[无模型密钥的候选校验]
    C --> D[保存正式稿]
    D --> E[无模型密钥的静态构建和扫描]
    E --> F[独立公开静态仓库]
```

选择双仓库是当前实施决策：源码仓库保持私有，公开仓库只接收扫描后的静态产物与最小发布配置。GitHub Free 支持公开仓库 Pages，私有仓库 Pages 取决于套餐；本次账号接口未返回可用套餐信息，因此不以私有 Pages 权益作为前提，也不自动将源码公开。[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

公开仓库使用独立项目地址，不改动其他网站。确切仓库名称和 Pages 基路径在创建资源后以 GitHub 返回值为准；配置中的仓库与公开地址保留 `null`，不填入假地址。
