# 验证记录与人工验收

## 已执行

- TypeScript 类型检查。
- 核心逻辑测试：有效日期、闰年、月历偏移、跨年、北京时间边界、中英文组合检索、备份校验、内容解析和稳定编号。
- 代码静态检查，排除未修改的第三方 UI 组件。
- 静态构建，并检查每日简报和跨年深层链接可生成。
- 根路径与 `/briefing-atlas` 子路径均通过构建产物检查：10 个页面、12 个稳定新闻锚点及资源引用。另对静态子路径预览执行 HTTP 检查，确认资源可加载、缺失日期返回 404。
- 开发服务器 HTTP 检查：首页、归档、搜索、收藏、最新详情、跨年详情与搜索索引。
- 依赖审计：当前锁文件无已知漏洞报告。

构建后运行 `npm run verify:build` 检查页面、锚点、资源引用、草稿隔离与构建隐私；设置 `NEXT_PUBLIC_BASE_PATH` 后可重复验证项目子路径。

## 浏览器人工验收清单

以下为待人工检查项目，不能视为已执行的浏览器自动化结果。

- 宽屏、手机和 200% 缩放下，正文、日历和搜索条件可用且无横向溢出。
- 键盘可进入主导航、年月选择、日期、搜索与阅读控件；方向键可在日期之间移动。
- 点击无内容日期只提示暂无简报，不跳转至其他日期。
- 搜索 `LoRA`、`低秩`、`RAG 检索`，检查主题、机构和日期联合过滤。
- 复制新闻链接并在新页面打开，检查稳定锚点与正文展开。
- 收藏、已读、主题和字号在刷新后保留；新标签页能接收状态修改。
- 导出备份后导入，验证合并；损坏 JSON 和超大文件不会改变原有记录。
- 禁用本地存储时有明确提示，页面其他阅读功能继续工作。
- 深浅模式、代码块、数学公式及缺失配图保持可读。

WebMCP 注册采用渐进增强，缺少支持的验证上下文，尚未完成其注册和执行契约的端到端验证。
