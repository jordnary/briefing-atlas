# 阅读与搜索

## 搜索

搜索页在浏览器中加载只读索引；每次查询都由同一套纯函数完成解析、筛选、相关度计算和摘录生成。空格默认表示 `AND`，高级设置可以切换为 `OR`；支持括号、`AND`、`OR`、`NOT`、前缀排除（`-关键词`）、连续短语和英文前缀匹配（`agent*`）。字段限定包括 `title:`、`summary:`、`body:`、`tag:`、`entity:`、`source:`、`briefing:`、`date:`、`before:` 和 `after:`，例如：

```text
title:(Agent OR 模型) -body:游戏
body:"incident report" entity:OpenAI after:2026-08-28
date:2026-09 agent*
```

`date:` 支持 `YYYY`、`YYYY-MM` 和 `YYYY-MM-DD`；`before:` 与 `after:` 不包含当天。页面日期筛选包含起止当天。英文词按单词边界匹配，中文按连续文字匹配；需要搜索括号、冒号、星号或运算符本身时使用引号。无效表达式会停止出结果并显示错误提示。每次查询最多 2,048 个字符、64 个条件和 12 层括号 / 否定嵌套。

结果默认按相关度排序。标题、摘要、正文、主题、机构、来源和导读拥有独立权重，评分使用词频饱和、逆文档频率和正文长度归一化；高级设置可使用默认、均衡或正文优先预设，也可逐字段调整。排序、搜索范围、匹配方式、日期、已读状态和自定义权重都可以通过“复制搜索链接”分享并在刷新或返回后恢复。

索引加载后校验稳定 ID、日期、必要字段类型、来源 URL；格式异常时提供重试。搜索摘录来自正文或元数据文字，排除图库说明和 Markdown 链接目标。`search_briefing_archive` WebMCP 工具复用同一解析和评分逻辑，返回 `{ total, offset, hasMore, results }`；默认每页 20 条，最多 100 条，支持排序和自定义权重。

默认权重依次为标题 8、摘要 3、正文 1、主题 4、机构 4、来源 1.5、本期导读 0.5。权重范围为 0–20；0 只取消加分，不排除字段。没有关键词或只有否定 / 日期条件时按日期和稳定 ID 排序。结果高亮仅来自实际成立的正向条件；本期导读命中会明确标注，可能对应同一期的多条新闻。

搜索采用字面匹配，不包含语义扩展或拼写纠错。阅读状态选项可通过 URL 恢复，具体已读与收藏记录仍属于各自浏览器。

## 阅读记录

收藏、已读、文章阅读位置和排版设置只保存在当前浏览器，沿用原有存储键。备份导入会合并收藏和已读，使用备份中的阅读设置。不同设备不自动同步；清理浏览器前可在“我的收藏”导出备份。简报卡片的“阅读全文”会进入 `/read/<date>/<story-id>/` 独立阅览页，页面支持目录、续读、阅读进度和打印样式。

## 文章排版

文章页默认采用宽屏布局，标题、摘要、正文和来源使用同一内容宽度。外侧留白随屏幕调整，手机保留每侧 12px 的页面边距。

| 阅读宽度     | 桌面布局最大宽度（含目录） | 专注模式最大宽度 |
| ------------ | -------------------------- | ---------------- |
| 标准         | 1440px                     | 1120px           |
| 宽屏（默认） | 1680px                     | 1440px           |
| 铺满         | 使用可用宽度               | 使用可用宽度     |

实际宽度不超过屏幕可用空间。较窄屏幕将侧栏目录切换为折叠目录，正文不会保留原先的 650px 上限。

右下角悬浮工具始终可用，无需返回顶部。加减按钮按 5% 调整整篇文字；展开“阅读设置”后可使用滑块和加减按钮细调。

| 设置     | 范围     | 步长 | 作用范围                                               |
| -------- | -------- | ---- | ------------------------------------------------------ |
| 整篇缩放 | 80%–150% | 5%   | 文章标题、摘要、正文、来源、图注和文章内辅助文字       |
| 标题大小 | 80%–140% | 5%   | 主标题、正文各级标题、独立加粗标题段和来源等分区标题   |
| 正文大小 | 16–28px  | 1px  | 正文、列表、引用、代码和表格；沿用简报页的正文字号偏好 |

整篇缩放叠加在标题与正文设置上。例如，正文设为 20px、整篇缩放设为 125% 时，实际正文字号为 25px。站点导航和悬浮设置面板保持原字号，避免调整过程中控件变形。

字号滑块支持键盘方向键。关闭按钮和 Escape 会关闭设置并将焦点送回入口；点击面板外或将焦点移出设置也会关闭。小屏面板可独立滚动，底部保留安全区域；打印时隐藏悬浮工具。

所有偏好保存在当前浏览器。旧备份保留原有字体、宽度、行距、收藏和阅读位置，新增缩放项补为 100%；新的字号与铺满选项可随备份导入导出。“恢复默认排版”恢复宽屏、18px 正文、100% 缩放、现代黑体、舒展行距和系统主题，保留收藏、已读和阅读位置。

## 图片阅读

文章内图组采用单张大图展示，保留原图比例。上方 44px 按钮切换前后图片，下方指示点可直接选图；手机支持左右滑动，键盘支持方向键与 Home / End。切换由读者控制，没有自动播放。字号调整和窗口缩放会保留当前图片。

图注默认使用 15px 字号并跟随整篇缩放，最小保持 14px。过长图注先显示两行，通过“展开图注”查看完整内容和来源链接。图片与图注分区留白，长注释不会把其他图片的展示区域撑高。

点击“放大查看”进入适应屏幕的大图预览，可继续切图或打开原图。Escape、关闭按钮和预览边缘可退出，焦点返回当前图片。预览期间锁定背景滚动；支持夜间主题、减少动态效果偏好和图片加载失败占位。打印时按顺序展开所有图片及完整图注。

构建时图组携带转义后的结构化图片数据，正文片段保留原有 HTML。复杂或嵌套的 Markdown 图组保留原展示，避免拆断正文结构。产物校验分别检查正文片段、每张图片和完整图注。

## 动效与可访问性

简报卡片首次进入视口时轻微浮入，每次挂载只播放一次。减少动态效果、打印、禁用 JavaScript 或不支持观察器时直接显示；键盘焦点进入和目录锚点跳转不被动画遮挡。组件维护方式见 [入场动画](DEVELOPMENT.md#入场动画)。

## 实验检索接口

搜索页保留只读 `search_briefing_archive` WebMCP 接口，复用普通检索逻辑，不支持或注册失败时自然降级。真实实验性浏览器中的注册与生命周期仍未完成端到端验证；普通搜索和阅读独立可用。测试入口见 [开发与发布](DEVELOPMENT.md#检查与测试)。
