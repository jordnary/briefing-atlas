## briefing-2026-09-06-01

原配图暂未恢复

[Anthropic](https://www.anthropic.com/?utm_source=chatgpt.com) 9 月 4 日公布了一项很有分量的 AI-for-Science 结果：Claude 在约 **11 天**内基本自主地把费马大定理完整形式化为 Lean 证明，最终生成约 **1300 万行 Lean 代码**、证明 **29,500 个中间定理**，形成 Anthropic 所称的首个端到端、可由计算机检查的 FLT 完整证明。这里的突破不是发现一个替代 Wiles 的新数学证明，而是把已有复杂数学论证转化成机器能够逐步验证的形式。（原引用链接暂未恢复）

**为什么重要：** 数学研究长期存在一个越来越明显的问题：AI 可以产生大量推理，但人类验证高难度结果可能需要数月甚至数年。Formal verification 给出了另一条路线——让 AI 不只是“提出证明”，还必须把每一步变成 proof assistant 可以机械检查的对象。

**实践 / 研究启示：** 这对 AI Scientist 的意义可能比单纯数学 benchmark 高很多。未来更可信的科研 Agent 很可能遵循：

\[
\text{Generate}
\rightarrow
\text{Formalize}
\rightarrow
\text{Machine Verify}
\rightarrow
\text{Human Interpret}
\]

也就是说，**Verifier 可能和模型本身一样重要**。

## briefing-2026-09-06-02

9 月新提交的 **Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement** 非常值得关注，尤其是 Vibe Gaming。来自 Shanghai AI Laboratory 的研究者没有继续单纯强化底层 LLM，而是在现有 Coding Agent 外再加一层“Harness 的 Harness”，把长期开发组织成反复的 **planning → coding → testing → evaluation** 循环。（原引用链接暂未恢复）

最有意思的实验之一正是游戏：Agent 从高层需求出发，逐步构建出一个**人类可玩的第一人称射击游戏**，包含剧情、战斗、武器、敌人交互、HUD、菜单、动画以及视觉和音频表现。框架还保留版本化项目历史，并要求每一轮既修复已有问题，又增加一个规模较小、能够验证的新能力。（原引用链接暂未恢复）

**为什么重要：** 这比“Prompt → 一次生成游戏”更接近真正的软件开发。论文指出，长任务真正困难的地方不是让 Agent 多运行几个小时，而是随着修改不断累积，如何避免**忘记早期需求、局部修复破坏全局设计、反复修同一个问题以及过早宣布完成**。（原引用链接暂未恢复）

**实践 / 研究启示：** 这几乎就是目前 Vibe Gaming 最值得研究的架构：

\[
\text{High-level Goal}
\rightarrow
\text{Planner}
\rightarrow
\text{Small Verifiable Increment}
\rightarrow
\text{Coding}
\rightarrow
\text{Play/Test}
\rightarrow
\text{Independent Evaluation}
\rightarrow
\text{Next Iteration}
\]

所以接下来研究 Codex / Claude Code 时，**Harness Engineering 与持续验证机制**很可能比继续堆 Prompt 技巧更有价值。（原引用链接暂未恢复）

[NVIDIA](https://www.nvidia.com/?utm_source=chatgpt.com) 在 IFA 2026 推出了 **PAIR（Personal AI Router）**：一个免费的开源工具，可以自动发现局域网里的 RTX PC、DGX Spark，甚至 Apple M4 及更新设备，把闲置计算资源组合起来运行本地 AI inference。设备可以动态加入或离开，PAIR 会重新分配任务；NVIDIA 同时宣布 llama.cpp / vLLM 本地推理优化，宣称最高带来约 **1.9×** 性能提升。（原引用链接暂未恢复）（原引用链接暂未恢复）

它还在推动 Hermes Agent、OpenClaw 和 Perplexity Portable Computer 等 Agent 应用简化本地安装，并将在 10 月推出新的 RTX Spark Windows PC。（原引用链接暂未恢复）

**为什么重要：** AI 算力过去基本有两种形态：

\[
\text{单台 PC}
\quad\text{或}\quad
\text{Cloud GPU Cluster}
\]

PAIR 开始尝试第三种：

\[
\boxed{\text{Personal Distributed AI Cluster}}
\]

这对隐私敏感、持续运行的 Agent 尤其有吸引力——不必把屏幕、代码仓库和私人文件持续发送到云端。

**实践 / 研究启示：** 本地 Agent 很可能越来越采用 **local-first + cloud escalation**：小模型负责文件搜索、日志分析、简单 Coding 和长期后台任务；遇到高难度推理时才调用 Astra / Claude / Gemini 一类 frontier model。这会同时降低成本和隐私风险。
