[Google](https://www.google.com/?utm_source=chatgpt.com) 于 **9 月 2 日**正式发布 Gemini **3.8 Flash** 和面向受信任防御者的 **3.8 Flash Cyber**。Google 将 3.8 Flash 称为目前最强的 Flash reasoning/coding 模型，重点提升软件工程、多步骤推理和 Agent 任务；开发者现在已经可以通过 Gemini API、AI Studio、Android Studio 和 Antigravity 使用。[blog.google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/?utm_source=chatgpt.com)

更值得注意的是价格：目前仍是 **$0.75 / 百万输入 tokens、$3.75 / 百万输出 tokens**，与 3.7 Flash 的首发价格相同。不过 Google 已明确说明该优惠价只持续到 **2026 年 12 月 31 日**，之后分别提高到 $1.50 和 $7.50。[blog.google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/?utm_source=chatgpt.com)

**为什么重要：** Frontier-model 市场正在出现一种越来越清晰的分层：最昂贵模型处理少数极困难任务，而大量 Coding / Research / Enterprise Agent 会转向 **“足够聪明但极便宜”的 Flash-class 模型**。Google 在六周内已经进行了三次 Flash 更新，说明这一层正在成为新的主战场。[blog.google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/?utm_source=chatgpt.com)

**实践 / 研究启示：** 做 Agent 时，不应该再默认所有步骤都调用最强模型。更合理的架构会是：

\[
\text{Cheap Flash Model}
\xrightarrow{\text{大部分任务}}
\text{Frontier Model}
\xrightarrow{\text{困难任务升级}}
\]

尤其是 Coding Agent / Vibe Gaming 中的日志分析、文件搜索、简单代码修改、Playtest 判断等任务，很适合使用这种 **model routing**。

今天研究部分选择稍早但非常值得关注的 **Agentic Proposing: Enhancing Large Language Model Reasoning via Compositional Skill Synthesis**。论文让一个专门的 Agent 不断组合数学、Coding 和科学 reasoning skills，自主生成**可验证的高难度训练轨迹**，再拿这些数据训练 reasoning model。[arXiv](https://arxiv.org/abs/2602.03279?utm_source=chatgpt.com)

最醒目的结果是：一个 **30B solver 只使用约 11,000 条 Agent 合成轨迹训练，就在 AIME25 达到 91.6% accuracy**。作者认为，高质量、可验证、针对性极强的 synthetic reasoning signals，有机会替代很大一部分昂贵的人类标注数据。[arXiv](https://arxiv.org/abs/2602.03279?utm_source=chatgpt.com)

**为什么重要：** LLM 的下一轮竞争可能不仅是：

\[
\text{更多参数}+\text{更多互联网数据}
\]

而越来越变成：

\[
\text{模型自己生成困难问题}
\rightarrow
\text{自动验证}
\rightarrow
\text{挑选高价值轨迹}
\rightarrow
\text{训练下一代模型}
\]

这也是一种非常具体的 **self-improvement loop**。

**研究启示：** 对机器学习研究而言，值得特别关注 **Synthetic Data + Verifier + RL + Curriculum Generation**。尤其是在数学、Coding 等答案可以自动验证的领域，未来最珍贵的资源可能不再是“拥有最多数据”，而是**拥有最好的自动出题器和验证器**。
