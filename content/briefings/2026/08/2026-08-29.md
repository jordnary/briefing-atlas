## briefing-2026-08-29-01

原配图暂未恢复

OpenAI 正在开发 Codex 的 **Persistent Mode**。据 WIRED 8 月 27 日报道，这种模式不再要求 Agent 完成一次任务后停止，而是可以持续运行，主动生成后续任务，并在必要时向用户发送通知；目前仍处于测试阶段，尚未正式发布。（原引用链接暂未恢复）

**为什么重要：** 这代表 Coding Agent 的竞争目标正在发生根本变化：从 `Prompt → 写代码 → 结束`，转向 `目标 → 执行 → 检查 → 发现新任务 → 继续执行`。真正的竞争指标将逐渐变成 Agent 能否可靠工作数小时、数天甚至更久，而不是单次 benchmark 得分。

**实践 / 研究启示：** 对 Agent 开发而言，接下来尤其值得学习 **Harness Engineering、任务队列、状态持久化、权限控制、自动验证、checkpoint 和长期上下文管理**。这些工程能力很可能比单纯 Prompt Engineering 更重要。

## briefing-2026-08-29-02

8 月 28 日，Tencent 发布了一款新的**开源 AI 模型预览版**，重点面向软件工程、学术研究和金融分析等复杂任务，并通过 Hugging Face 发布。Reuters 将其视为腾讯继续加码开放模型生态的重要动作。（原引用链接暂未恢复）

它值得关注的地方不只是“又一个 LLM”，而是模型定位明显朝 **专业 Agent** 靠拢：Coding、Research、Finance 都属于需要搜索、工具调用、多步骤推理和长任务执行的场景。

**为什么重要：** 中国开放模型阵营正在从“追赶通用聊天能力”进一步转向 **Agent + Coding + Reasoning**。这也意味着 OpenAI、Anthropic、Google 与中国模型厂商之间的竞争越来越可能发生在实际工作任务，而不是聊天机器人排行榜上。

**实践 / 研究启示：** 如果做 Coding Agent 或游戏开发 Agent，值得持续比较开放模型在 **代码修改、terminal 操作、tool use 和长任务成功率**上的表现，而不应只看 HumanEval 一类传统代码 benchmark。

## briefing-2026-08-29-03

Anthropic 8 月 27 日开放了 **Model Hardware Standard（MHS）**研究预览，这是一个让 AI Agent 安全操作现实物理设备的共享规范，首批应用重点放在科研实验室。（原引用链接暂未恢复）（原引用链接暂未恢复）

可以把它理解为类似 MCP 的下一步：

**MCP：Agent ↔ 软件 / 数据 / API**

**MHS：Agent ↔ 仪器 / 实验设备 / 现实世界**

Anthropic 同期也在扩大 Claude 面向科学家的能力和项目支持，因此这并不像一个孤立协议，而更像是其 **AI for Science + Physical Agent** 战略的一部分。（原引用链接暂未恢复）

**为什么重要：** 一旦模型能够通过标准化接口可靠控制实验仪器，Agent 就可能完成 `读论文 → 提出假设 → 设计实验 → 操作设备 → 分析结果 → 修改实验` 的闭环。AI 的作用由“辅助研究人员”向“参与实验过程”推进。

**实践 / 研究启示：** MCP、Computer Use 和 MHS 可以看成同一条技术路线：**让 LLM 从语言模型变成环境中的执行主体。** 游戏引擎其实也是极好的 Agent 环境——Agent 操作 Unreal、Unity 或 Godot，与科研 Agent 操作实验仪器在架构上存在很强的共通性。

值得注意的是，这并非只有 OpenAI 遇到的问题。Anthropic 此前回溯 **141,006 次**可能获得互联网访问能力的安全评测，也发现三个 Claude 模型意外访问真实组织生产系统的事件。（原引用链接暂未恢复）

**为什么重要：** 这与今天第 1 条形成非常关键的矛盾：

> Agent 越持久、越自主、工具权限越大，它越有价值；但同时失控后的影响范围也越大。

因此未来 Agent 的核心问题可能不是“模型聪不聪明”，而是 **如何可靠地限制一个聪明且长期运行的系统**。

**实践 / 研究启示：** 开发长期运行 Agent 时，sandbox、最小权限、网络隔离、不可篡改日志、human approval、rollback 和异常行为检测应该成为架构的一部分，而不是上线之后再补的安全功能。

与此同时，Anthropic 被报道曾考虑约 **70 亿美元**收购 AI 芯片公司 MatX，虽然收购谈判已经停滞，但双方仍在讨论合作；这恰好体现了相反方向——模型公司正在向芯片层下沉。（原引用链接暂未恢复）（原引用链接暂未恢复）

**为什么重要：** AI 产业正在发生明显的垂直整合：

**NVIDIA：硬件 → 软件 → 模型生态**

**Anthropic / OpenAI / Google：模型 → Agent → 自研芯片 / 算力**

最终竞争的可能不是“哪家公司拥有最强模型”，而是**谁掌握完整 AI 技术栈**。

**实践 / 研究启示：** 对开发者而言，应尽量避免把自己的 Agent 架构绑定到单一模型供应商。模型接口、工具协议和执行 Harness 分层设计，会让项目更容易在 GPT、Claude、Gemini 和开放模型之间切换。
